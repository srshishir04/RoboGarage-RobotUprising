# Unity/ — Robo Garage Uprising

Unity 6 (`6000.3.8f1`) project. ML-Agents `4.0.2`, ONNX Runtime for in-editor inference.

## Scenes (`Assets/Scenes/`)

| Scene | Purpose |
|---|---|
| `MainMenu.unity` | Difficulty (Easy/Medium/Hard) + mode (1v1/2v2) selection. Loads `GameScene`. |
| `GameScene.unity` | Live physical-match visualizer — camera feed + HUD (score, timer, connection status). No simulated physics; the ball/robots are real. |
| `TrainingArena.unity` | ML-Agents training scene (simulated arena, `RobotAgent` vs `ScriptedOpponent`). |

## Scripts (`Assets/AI Scripts/`)

| Script | Role |
|---|---|
| `RobotAgent.cs` | ML-Agents `Agent` — training + ONNX inference for the AI robot. |
| `ScriptedOpponent.cs` | Non-RL training sparring partner. |
| `GameSettings.cs` | Central settings: difficulty, match mode, derived obs size and brain filename. |
| `MainMenuUI.cs` | Main menu logic and brain-file-present warning. |
| `LiveMatchManager.cs` | Match clock/score authority. |
| `GameSceneUI.cs` | Match HUD; routes UDP goal/status events from `brain_runner.py`. |
| `CameraControl.cs` | Receives the processed camera feed from Python (UDP), sends exposure/gain back. |
| `FrameSender.cs` | Sends `START:<difficulty>:<match>` / `STOP` to `brain_runner.py`. |

## Brain files

`GameSettings.OnnxFileName` follows the convention `<mode>_<difficulty>.onnx` (e.g.
`1v1_easy.onnx`, `2v2_hard.onnx`), matching `ai_robot/brains/`. It's re-derived whenever either
difficulty or match mode changes (`SetDifficulty`/`SetMatchMode`), since 1v1 and 2v2 each need
their own trained brain per difficulty. `brain_runner.py` loads the actual file — Unity only
uses this name for the on-screen "brain ready" check.

## ML-Agents training config

Trainer hyperparameters (`.yaml`) are not yet checked into this repo — add them under
`Unity/config/` when available. Without this file, the exact hyperparameters that produced the
committed `.onnx` brains aren't reproducible from git history alone.

## Housekeeping

`Library/`, `Logs/`, `Temp/`, `obj/`, `UserSettings/` etc. are gitignored (`Unity/.gitignore`)
— they're regenerated by the editor and should never be committed.

An older, unrelated prototype (`MainController`/`RobotController`/`StreamCameraController`/
`VideoServer`/`GoalController` + a `MainScene.unity`) was removed — see
`PROJECT_CLEANUP_PLAN.md` at the repo root for why.
